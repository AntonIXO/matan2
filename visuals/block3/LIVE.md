# Живые объяснения в Blender

Открыть `differentiation_live.blend`. Все пять тем — настоящие анимированные сцены Blender, без предварительного рендера кадров.

- **Space** над 3D-окном — пуск / пауза. Кадр можно выбрать на нижнем таймлайне.
- **Матан · темы** в заголовке 3D-окна — выбор темы.
- Панель **Матан · живые объяснения** находится справа, во вкладке свойств сцены; также доступна через **N → Матан**.
- **Следующий / предыдущий шаг** останавливает движение и открывает опорный кадр доказательства.
- **½× / 1× / 2×** меняет скорость просмотра. **Вернуть камеру** восстанавливает учебный ракурс после вращения вида.

| Тема | Что движется | Длительность при 1× |
|---|---|---|
| Дифференцируемость | Поверхность сближается с плоскостью при увеличении окрестности; относительный остаток уменьшается | 30 с |
| Лесенка | Точка проходит два координатных участка; промежуточные точки и частные наклоны приближаются к значениям в a | 34 с |
| Композиция | Сетка последовательно деформируется под F и G, затем при увеличении совпадает с линейными образами | 34 с |
| Векторная Лагранжа | Точка проходит кривую; возникают проекции перемещения и скорости; затем показывается обход окружности | 41 с |
| Градиент | Единичное направление вращается; меняются сечение поверхности, касательная и знаковая шкала наклона | 35 с |

В конце каждой темы обычное воспроизведение Blender возвращается к началу. Для спокойного разбора используйте паузу или кнопки отдельных шагов. Вращение 3D-вида сохраняет настоящую пространственную геометрию; учебные подписи рассчитаны на сохранённую камеру.

## Повторное открытие

Геометрическая анимация записана в shape keys и ключевые кадры: **Space работает без запуска скриптов и без MCP**.

Кнопки панели — небольшой Python-интерфейс. Он уже включён в текущем сеансе. Если после повторного открытия панели нет, во встроенном Text Editor выберите **START_Матан.py** и нажмите **Run Script**. Тот же код сохранён рядом в `live_controls.py`. Глобальные настройки доверия к скриптам не менялись.

## Точность иллюстраций

Формулировки, примеры и источники описаны в `README.md`; анимации используют ту же математику. В частности:

- При уменьшении окрестности в первой теме все пространственные координаты увеличиваются одинаково, без искусственного сжатия вертикали.
- В композиции плавный переход сетки в её образ — визуальное построение. По завершении каждого перехода сетка точно соответствует выбранным F и G. При уменьшении радиуса координаты композиции вычислены как полиномы от радиуса, включая члены до третьей степени после нормировки.
- В теме Лагранжа для иллюстративной кривой $F(t)=(\cos t,\sin t,0.4t)$, $t\in[0,\pi]$, отмеченная точка $c=\arcsin(2/\pi)$ действительно удовлетворяет скалярному равенству Лагранжа для функции проекции. Это частный пример, не способ выбора c в общей теореме.
- Стрелка в контрпримере с окружностью передаёт направление скорости; её длина уменьшена для читаемости.
- В градиентной сцене сечение — именно $f(a+tu)$; нулевая производная в a не означает постоянства функции на всей прямой.

`build_live.py` создаёт сцены внутри Blender через MCP. Для обычного просмотра повторная сборка не нужна. Ключевые кадры можно свободно менять штатными средствами Blender.
