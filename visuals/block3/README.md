## Математика выбранных примеров

В кадрах 01 используется $f(x,y)=x^2+2y^2$, $a=(1/2,1/4)$, поэтому

$$df_a(h)=h_1+h_2,\qquad r(h)=h_1^2+2h_2^2,\qquad 0\le r(h)/\|h\|\le2\|h\|.$$

Полуширины квадратного окна: 0.65, 0.2, 0.06. Все три пространственные координаты центрируются в точке графика и делятся на полуширину. Красный отрезок наложен поверх поверхности в той же ортографической проекции, чтобы его не закрывала непрозрачная геометрия.

В кадрах 02: $a=(0.2,0.1)$, $x=(1.05,0.75)$; промежуточные точки для квадратичной функции: $(0.625,0.1)$ и $(1.05,0.425)$. В тексте сохраняется общая формулировка доказательства.

В кадрах 03: $a=b=0$,

$$F(x,y)=(x+0.5y+0.3y^2,\ 0.2x+y+0.25x^2),$$
$$G(u,v)=(1.1u+0.6v+0.2v^2,\ -0.3u+0.9v+0.15u^2).$$

$$A=F'(0)=\begin{pmatrix}1&0.5\\0.2&1\end{pmatrix},\quad B=G'(0)=\begin{pmatrix}1.1&0.6\\-0.3&0.9\end{pmatrix},\quad BA=\begin{pmatrix}1.22&1.15\\-0.12&0.75\end{pmatrix}.$$

Бирюзовая сетка — точный образ, жёлтая граница — образ под линейным оператором. Каждая точка сетки вычислена формулой; полилинии аппроксимируют кривые. Красный отрезок соединяет точное и линейное приращения. У всех трёх панелей один масштаб.

В кадре 04a: $F(t)=(\cos t,\sin t,0.4t)$, $[a,b]=[0,\pi]$. Скорость показана при $t=\pi/4$: это не выбранная точка c из теоремы. Проекция вычисляется как $v\langle v,F'(t)\rangle/\|v\|^2$. В кадре 04b короткие стрелки передают направления скорости вдоль единичной окружности; их длина для читаемости уменьшена.

В кадрах 05: $\nabla f(a)=(1,1)$; три единичных направления дают производные $\sqrt2,0,-\sqrt2$. Стрелки на карте показывают направления. Нулевая производная означает отсутствие линейного изменения в точке, а не постоянство на всей прямой.

## В Blender

Каждый кадр — отдельная сцена с префиксом `MATAN_`. Исходная пользовательская `Scene` сохранена. Камеры ортографические; шрифт упакован в `.blend`. Выберите нужную сцену в верхнем списке, затем Render Image. Это статические учебные кадры, не анимация.

Генератор запускается внутри Blender. Он добавляет сцены, не удаляя существующие. Повторный запуск создаст дополнительные сцены; для чистой повторной сборки используйте новый файл Blender. Вызывать `build_all()` и `render_queue(scenes)` можно через тот же Blender MCP.
