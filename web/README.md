# Матан · геометрия

Локальное веб-дополнение к конспекту К. П. Кохася: **34 сцены, 156 управляемых шагов, ссылки на 69 билетов**. Пять исходных Blender-моделей перенесены в вычисляемую геометрию браузера. PDF остаётся основным конспектом; собственные примеры и дополнения отмечены в карточках.

## Запуск

Нужны Bun, Python 3 и Typst, доступные в PATH. Python использует только стандартную библиотеку.

Из каталога web:

```sh
bun install --frozen-lockfile
bun run sync
bun run dev
```

Сайт: <http://127.0.0.1:5173/s2/>. Путь /s2/ совпадает с будущим адресом https://math.devpins.org/s2/. Публичное размещение не выполнялось.

Готовая статическая сборка:

```sh
bun run build
bun run preview
```

Предпросмотр сборки: <http://127.0.0.1:4173/s2/>. Результат находится в dist; сервер приложений, база данных и внешние сервисы не нужны. Развёртывание не выполнялось.

## Управление

- Сцены идут по порядку основного билета в конспекте, с разделами определений и теорем каждого блока. Поиск работает по названию и номеру; обязательность берётся из конспекта.
- Шаги доступны независимо. Кнопки, пробел и стрелки влево/вправо управляют рассказом.
- Время воспроизведения и математические параметры разделены. Ручная настройка ставит сцену на паузу; продолжение начинается с выбранного положения.
- «Все шаги» включает последовательное воспроизведение. По умолчанию проигрывается только текущий шаг.
- Точки с кольцом перетаскиваются мышью или пальцем и перемещаются стрелками при фокусе.
- Пространственная камера поворачивается перетаскиванием; колесо меняет масштаб. «↺ Вид» восстанавливает камеру, «Сбросить» — учебный пример.
- Кнопки под формулой связывают её объекты с подсветкой рисунка.
- Ссылка сохраняет урок, шаг и параметры. Поддерживаются и метки билетов: например #th-b1-29 открывает шаг о трапециях.
- При reduced motion воспроизведение переходит к опорному состоянию без движения. В скрытой вкладке оно останавливается.
- Для пространственных сцен требуется WebGL 2.

## Источники и сборка PDF

Команда sync обновляет ../web-scenes.json из каталога, компилирует ../main.typ в ../main.pdf, получает физические страницы заголовков через typst query, собирает обязательность из ../lib.typ и копирует PDF и Blender-файлы в public. Под заголовками конспекта правило в lib.typ выводит ссылки на связанные сцены по адресу https://math.devpins.org/s2/. Математический текст глав остаётся прежним.

Генерируются src/generated/notes.json, public/notes.pdf и public/blender. Карта web-scenes.json входит в исходники: обычная команда typst compile main.typ работает без Bun. При каждой сборке PDF и индекс получают одну ревизию исходников. Страницы ссылок не записываются вручную.

Математические источники: ../chapters, ../clean/лекция_NN.txt, ../visuals/block3/README.md и соответствующие генераторы. В карточках даны ссылки в PDF, а для восстановленных фрагментов — также ссылки на лекцию.

Приёмы подачи: синхронный параметр и объект — [Bartosz Ciechanowski](https://ciechanow.ski/curves-and-surfaces/); элемент, сумма, уточнение — [3Blue1Brown](https://www.3blue1brown.com/lessons/essence-of-calculus/); сохранение траектории — [Bret Victor](https://worrydream.com/LadderOfAbstraction/); общая подсветка — [Amit Patel](https://simblob.blogspot.com/2021/06/highlighting-diagrams-and-text-together.html).

## Проверки

```sh
bun test
bun run test:browser
bun run format:check
bun run build
```

- Bun проверяет аналитические равенства, предельные соотношения, геометрические ограничения, пути Гекса, формулы, ссылки и восстановление состояния.
- Playwright проходит каждый шаг и крайние параметры, проверяет паузу/продолжение, клавиатуру, мышь, сенсорные события и отсутствие лишних кадров на паузе.
- Раскладка проверяется при 375, 768 и 1440 px. Визуальные кадры дополнительно просматриваются вручную.
- Прогон выполнен в Chromium на Linux. Safari и Firefox отдельно не проверялись.

Для установки браузера:

```sh
bunx playwright install chromium
```

Если загрузка недоступна, тестовый запуск умеет использовать уже установленный Chromium из кеша Playwright. Можно указать путь явно через PLAYWRIGHT_CHROMIUM_EXECUTABLE. MATAN_BASE_URL задаёт адрес уже работающей сборки для проверки.

Снимки всех 156 шагов и мобильных страниц при запущенном dev-сервере:

```sh
bun run capture
```

Снимки для просмотра сохраняются в test-results/visual, отчёт тестов — в playwright-report. Обновлять кадры следует после изменения геометрии или оформления.

## Структура

- src/lessons.ts, src/content — карточки в порядке основных билетов: условия, пример, параметры, шаги, источники и связи с билетами.
- src/math.ts, src/models.ts — математические модели.
- src/state.ts — ограничения параметров, шаги и ссылки.
- src/scenes — построения 2D/3D.
- src/App.tsx — каталог, объяснение, воспроизведение, управление.
- scripts/sync_links.ts — карта прямых ссылок в конспекте; scripts/sync_notes.py — PDF и обратные ссылки на страницы.
- tests — математические и браузерные проверки.

React 19, TypeScript, Vite, Three.js / React Three Fiber / Drei, Mafs и KaTeX. Формулы содержат MathML; 3D рисуется по требованию. Версии закреплены в bun.lock.

## Дополнительный интерфейс WebMCP

Если браузер предоставляет document.modelContext, регистрируются чтение каталога, чтение состояния, открытие сцены и атомарная настройка параметров. Они используют те же модели состояния, что и видимый интерфейс. Произвольный код и произвольные формулы не принимаются.

Контракт регистрации и действий проверяется тестовым реестром в Playwright. Нативного WebMCP в использованном тестовом Chromium нет; совместимость с конкретной нативной реализацией отдельно не подтверждена. Обычная работа сайта от него не зависит.
