# Конспект к экзамену по матанализу (С2, 2026, К. П. Кохась)

Цель: вытащить доказательства теорем из лекций (YouTube-субтитры) и связать
билеты в единую цепочку. Извлекаем только то, что есть в `bilety-opr.csv`.

## Файлы

| Файл | Назначение |
|------|-----------|
| `bilety-opr.csv` | Список билетов: теоремы + определения/формулировки |
| `clean_vtt.py` | Чистит сырые `.vtt` субтитры → `clean/лекция_NN.txt` |
| `gen_structure.py` | Генерирует структуру Typst из CSV |
| `lib.typ` | Стили и компоненты (`opr`, `dok`, `svyazi`, `todo`) |
| `main.typ` | Титул + оглавление со ссылками + `#include` глав |
| `chapters/0N-block.typ` | Главы по 3 тематическим блокам |
| `clean/` | Очищенные субтитры лекций (источник для извлечения) |

## Сборка

```sh
typst compile main.typ      # → main.pdf
typst watch main.typ        # авто-пересборка при правках
```

## Как заполняем

Каждый билет-теорема имеет три части: **Билет** (формулировка),
**Доказательство**, **Суть** (идея/зачем). Незаполненное помечено `#todo`.

Билеты «переплетаются» через метки и ссылки:
- у каждого заголовка есть метка, напр. `<th-b2-03>`, `<op-b1-05>`;
- зависимости билета указываем раскомментировав `#svyazi(<op-b1-05>, <th-b1-12>)`
  — это отрисует строку «→ опирается на: …» с кликабельными ссылками.

Схема меток: `op`/`th` (определение/теорема) + `bN` (блок) + порядковый номер.

## Блоки

1. Определённый интеграл, приложения, выпуклость, асимптотики (22 опр. / 40 теорем)
2. Несобственные интегралы и числовые ряды (10 опр. / 20 теорем)
3. Дифференцирование в R^m (13 опр. / 8 теорем)
